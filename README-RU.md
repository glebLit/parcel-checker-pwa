# ParcelChecker PWA — полный проект 2.0.1

Распакуйте архив. Это отдельный полный проект, не патч старого сайта.
Сканер ZXing-WASM 3.1.6 устанавливается при сборке через npm; WASM копируется из того же пакета.
Библиотека и WASM не включены в ZIP. Они будут внутри опубликованной сборки после успешного GitHub Actions.

## Публикация без команд
1. В старом приложении экспортируйте резервную копию JSON. Не удаляйте старый сайт.
2. Создайте НОВЫЙ публичный репозиторий parcel-checker-v2 с README и основной веткой main.
3. Add file → Upload files: загрузите содержимое распакованной папки, не ZIP.
   index.html и package.json должны оказаться в корне; src, public — рядом.
4. Settings → Pages → Source → GitHub Actions.
5. Если скрытая .github не загрузилась: Add file → Create new file.
   Имя: .github/workflows/deploy.yml
   Вставьте содержимое DEPLOY-WORKFLOW.txt из архива. Commit changes.
   Если файл уже загружен, для запуска после настройки Pages добавьте в него пустую строку и сохраните.
6. Публикация запустится автоматически. Actions → Deploy ParcelChecker.
   Дождитесь зелёного Deploy. При красном шаге откройте журнал и скопируйте ошибку.
7. Settings → Pages → Visit site. Для вашего аккаунта и предложенного имени ожидаемый адрес:
   https://gleblit.github.io/parcel-checker-v2/
   Это не уже опубликованный сайт. Здесь публикация не выполнялась.
8. На странице должна быть версия 2.0.1. Не используйте старый ярлык телефона.
   Сначала проверьте ручное добавление и камеру, затем импортируйте JSON-копию.
9. iPhone: Safari → Поделиться → На экран Домой. Android: меню Chrome → установка приложения.

## Локально
Node.js 22: npm install; npm run dev.
Production: npm run build; npm run preview.
Двойным щелчком index.html не открывать: нужен сборщик.
package-lock.json создаётся при npm install, его стоит сохранить для воспроизводимости зависимостей.

## Данные
TXT UTF-8: одна строка КОД|Описание|DONE. Описание и DONE необязательны.
Импорт заменяет список с подтверждением; лимит 10 МБ и 50 000 записей.
JSON сохраняет коды, описания, отметки и checkedAt. Ведущие нули в строковых кодах сохраняются.
Данные в отдельной IndexedDB версии 2.0.1; старый список автоматически не переносится.
Синхронизации между телефонами и вкладками нет: не работайте одновременно в нескольких вкладках.
Фото до 20 МБ, уменьшается до 2560 пикселей. Видео до 1600 пикселей для декодирования.
На снимке должен быть один код целиком. Размытый код может не распознаваться.
Камера требует HTTPS и разрешения. Низкопроизводительные устройства могут замедляться при распознавании.
После «Офлайн готов» проверьте закрытие и повторное открытие без сети. Регулярно экспортируйте JSON.
Не очищайте данные сайта без резервной копии.

## Проверки и ограничения
В этой среде проверен синтаксис JavaScript. Установка npm-зависимостей, production-сборка,
реальное распознавание, установка PWA и камера iPhone/Android здесь не выполнялись.
Не считайте этот архив уже протестированной на телефонах сборкой.
GitHub Actions выполняет установку, сборку и публикацию; после этого проверьте на своих устройствах.
